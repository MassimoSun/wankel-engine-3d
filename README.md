# Wankel Engine — Interactive 3D Cutaway

Explore a single-rotor engine with a freely rotating camera, a removable front cover, an adjustable axial cutaway, and animated intake, compression, power and exhaust phases.

The site opens in English. Use the **EN / RU** switch in the header to select English or Russian. Each phase has its own rotatable 3D preview.

## Run locally

Open `index.html` (English) or `ru.html` (Russian) in a modern browser. No installation, external libraries, API keys or build step are needed. Without WebGL the interactive SVG diagram remains available.

Drag to orbit, scroll to zoom, and use the cover and cut-depth sliders to look inside. The page supports touch, keyboard navigation and reduced-motion preferences.

## GitHub Pages

Publish from the `main` branch, `/ (root)`. The entry point is `index.html`; `.nojekyll` disables Jekyll processing.

## Model scope

This educational model keeps rotor motion, housing geometry and the 3:1 shaft-to-rotor speed ratio consistent. Gas-exchange timing and port placement are schematic. It is not a manufacturing model of a particular Mazda 13B.
